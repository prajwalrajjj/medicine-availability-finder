# Acknowledgments

**Medicine Availability Finder** borrows architecture and feature ideas from the open-source project **VitaMap**:

- Repository: [https://github.com/akasr/vitamap](https://github.com/akasr/vitamap)
- Authors: akasr and contributors
- Description: medicine availability search, pharmacy registration, inventory management, and map integration

Our implementation is a separate **Express + React + Prisma** codebase adapted for an AWS-focused college project (EC2, RDS PostgreSQL, S3, IAM, CloudWatch). The public product name remains **Medicine Availability Finder**.

If you publish or submit this work, cite VitaMap as a reference implementation and comply with its repository license.
